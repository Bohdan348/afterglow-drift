AFTERGLOW DRIFT — TEAM NOTES
Общий координационный файл команды разработчиков.
Правила:
  - каждый агент ведёт ТОЛЬКО свою секцию (ниже по имени), чужие НЕ трогает;
  - при старте задачи сначала прочитай весь файл и проверь предыдущие DONE-секции
    (npx tsc --noEmit + npm run build + при необходимости CDP быстрый прогон);
  - по завершении обнови свою секцию: статус, сделано, что проверить следующему, хвосты;
  - статусы: IN PROGRESS / DONE / BLOCKED. Закрывай [DONE] только когда проверено.
  - служебный файл процесса, не является частью продакшна игры.
БЭКАП-СТРАТЕГИЯ (для восстановления при ошибках/недовольстве):
  - git-репозиторий внутри game/; перед началом СВОЕЙ задачи каждый агент делает
    явный контрольный коммит-точку «backup-<N>` текущего рабочего состояния;
  - по завершении задачи агент делает коммит результата (feature-<имя> / fix-...);
  - если что-то пошло не так или пользователю не нравится — откатываемся к нужной
    «backup-<N>` точке (git checkout/reset) и продолжаем от неё;
  - НЕ коммитить в чужие ветки/файлы; коммит только своих изменений, явными именами.
РЕШЕНИЕ ПОЛЬЗОВАТЕЛЯ (текущее): контрольную backup-точку НЕ создаём сейчас —
  сохранить после полного выполнения проекта (все 7 задач), когда будет виден итог.
  Файлы, не связанные с фазой A (inspect*.mjs, profile.mjs, tools/) — НЕ трогать
